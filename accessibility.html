Accessibility statement

Our commitment

Standards followed

This dashboard targets WCAG 2.1 level AA and uses HTML5 semantic elements so assistive technology can understand the page structure.

Built-in features

  • Skip link to jump straight to the main content.
  • Landmarks: header, navigation, aside, main and footer.
  • Data tables with captions and header scopes.
  • Modal dialogs that trap focus and return it on close.
  • Forms with labels, fieldsets, hints and linked error messages.
  • Visible focus indicators and reduced-motion support.

Report a problem

If you find a barrier, email accessibility@example.com.
